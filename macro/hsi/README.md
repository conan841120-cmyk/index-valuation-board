# 恒生指数领先指标：云端更新模块

用户于2026-10-02确认本项目采用 `observation_period / quarter_end_carry_forward` 和 `explicit_unbiased`。这是生产计算口径的确定，不代表已取得原作者源码。

季度末3、6、9、12月更新最近两个已结束季度的名义GDP之和，并沿用到下一次更新。四因子分别按36个月半衰期、显式无偏加权方差标准化，再各乘0.25。信用脉冲固定为 `(SF6[t] - SF6[t-12]) / GDP2Q[t]` 的过去3个月均值。所有作者锁定参数由代码检查。

季度末还需要等待对应季度GDP实际公布。例如仅有第二季度GDP时，完整指标最多覆盖8月；不会在9月继续沿用旧两个季度分母并宣布9月完整指标。这个完整性门控不改变已有历史月份的计算。

`python update.py` 离线重算；`python update.py --refresh` 联网获取统计局官方社零同比、官方出厂价格同比指数、当季名义GDP、人民银行社融增量、金管局总额M2直接同比，以及恒指月末收盘价。源文件缓存至 `data/raw/`，处理后历史留在 `data/processed/`。每个数据集单独校验单位、覆盖和重复值；失败回滚到原处理后文件，并在网页标出沿用缓存。原始响应缓存由GitHub Actions保存，不提交进公开仓库。

金管局更新最近3个月公布材料；更早的逐月原始发布值保留。统计局与社融序列可能修订，当前历史不是完整历史数据版本。页面的经济观察期、公布日期、成功抓取时间和生成时间分别记录；不能把季度末的观察值视为当月已经可知。

估值工作流 `.github/workflows/daily.yml` 独立每天北京时间08:30抓取估值，保留本指标快照。宏观工作流 `.github/workflows/macro.yml` 每天18:30先执行无网络日历门控：PPI8—14日、社融8—16日、社零14—20日（2月无独立轮次）、M2为26日至月底、GDP为1/4/7/10月16—21日。某来源窗口后未取得数据则每天追踪，进入该来源下一轮仍缺旧轮次则报警。统计依据见根目录 `RELEASE_CALENDAR_REPORT.md`；窗口配置 `release_policy.json` 与指标算法配置独立。

轻量检查只查询近期数据、当前年度附表或相应月份公告目录。没有变化不重算；变化时仅更新对应来源和恒指对照数据。宏观流程使用现有估值输入离线重建同一页面，不抓取估值。两条流程共享发布锁，启动时检出最新main；平台调度和排队仍可能延迟。

`release_watch.py --plan`只用Python标准库，不访问来源；`release_watch.py`执行应检查的来源；`release_watch.py --force-refresh`手动忽略日历刷新全部来源。正常轮次和报警状态保存在根目录 `data/hsi_macro_monitor.json`。网页报警持续显示，新报警在发布后让GitHub任务失败（邮件由用户已有通知设置决定），相同报警不逐日重复通知。缺数据可能是尚未公布、官方接口滞后或抓取/解析失败，报警不假定官方一定已发布。

社零2月不等待独立1月同比；3月1—2月合并公告得到官方确认后关闭发布轮次，但1、2月独立同比仍为NaN。监测从上线时上一季度开始，不把几十年前未知发布日期的记录当成本轮抓取故障。同URL下的静默历史修订不保证由近期检查全部发现，需要时手动强制刷新。

输出：`../../data/hsi_macro.json`（网页快照）、`data/processed/historical_replication.csv`（可核验月度数据）、`output/diagnostics/indicator_diagnostics.csv`（完整分解）。网页CSV导出保留空值，虚线仅连接已知端点，不填写缺失月值。

验证：本目录运行 `python -m pytest -q`；仓库根目录运行 `node tests/test_macro_frontend.js`。
