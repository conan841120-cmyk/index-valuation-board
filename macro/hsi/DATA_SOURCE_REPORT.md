## 官方字段筛选

NBS 使用新版公开指标目录与 `/publicrelease/web/external/stream/esData` POST：全国地区维度、指定指标ID、时间段。原始字段目录及全历史 JSON 保存在 `data/raw/nbs_*`。

- 社零目录同时含“同比增长”（当月）及“累计增长”，只用前者。
- PPI 选择工业生产者出厂价格指数的“上年同月=100”。减100是已发布同比指数的表达转换，没有从金额自行推算同比。
- GDP 选“国内生产总值当季值 (亿元)”；元数据和官方GDP表注明现价。区分了累计金额、当季金额、同比增速。
- HKMA 附件 Table 1A 的 M2 行含 HK$ / Foreign currency / Total 三项，取 Total 的“earlier same month”增长列；不取港元子项或上月增长。
- 社融按官方“社会融资规模增量”当月总额读取。同一年度文件中的2017/2018/2019修订历史可能重叠，优先较新官方文件并保存重叠审计。结构百分比表的100曾在调查中触发异常，已排除并加入回归测试。

## 真实访问路径及失败处理

| 尝试 | 实际结果 | 最后处理 |
|---|---|---|
| NBS old easyquery | HTTP403 | 没有第三方替代；调查新版官方公开接口 |
| NBS新版首页/旧EsData路径 | 首页短历史不足；若干非流式请求报错 | 官方字段目录 + stream/esData 实际HTTP200，获得全历史 |
| HKMA官方supply-components-all API | 超时，无有效HTTP数据响应 | 继续调查官方下载文件及发布附件 |
| HKMA官方MSB/T020202.xls | HTTP200，但主要为余额 | 不自行算同比，排除 |
| HK政府统计处340-45011 YoY CSV | HTTP200，但实际季度频率 | 不冒充月度，不用于指标 |
| 官方C01.xls | HTTP200，是HK$ M3 | 因字段错误排除 |
| HKMA每月Monetary Statistics附件 | PDF/XLS/XLSX HTTP200 | 找到直接M2 Total YoY，181个月全部读取 |
| PBOC年度HTML、早期PDF | HTTP200 | 解析名义增量金额，审计重叠与扩围修订 |
| PBOC旧2025-01公告数字ID | HTTP404 | 通过官方新闻列表发现迁移后URL，正文核验实际2025-02-14 |
| Yahoo / Stooq / 腾讯恒指端点 | 超时、连接/端点失败 | 仅比较序列改用新浪；并以HKEX官方逐月核验 |
| 新浪日线、HKEX年鉴/月报 | HTTP200 | 重叠18个月（2013后段+近期13月）差异至多0.001点，优先官方 |

原始响应均缓存，而不是声称所有接口都成功。HTTP响应的元数据有状态码和SHA256，网络超时没有HTTP成功状态。每个数据源最终的非空行数、首末日期、单位、缺失与重复被程序再次打印检查。网络过程中遇到的暂时SSL/服务器失败，经有限重试及缓存继续完成，没有关闭TLS校验。

## 发布日期与版本边界

HKMA完整181个月都有原始发布日。NBS当前公开索引能核验约2021-10以后月份、2021Q3以后20季GDP；对应非空社零46个月、PPI59个月。PBOC索引及原公告共173个月实际日期。早期未知日期保持空，不以计划发布日或URL迁移日期代替。

NBS 的GDP“初步核算结果”表可能比发布会晚一天，本版使用较保守的表公告日。月末映射通常不受此影响；若要求日内最早可得时间，需进一步核验。

数值版本：NBS为latest-vintage revised history；社融为不同年度修订资料拼接；HKMA为逐月原始发布附件。特别是社融2025-01年度修订值70546亿元与最初公告四舍五入的7.06万亿元不同，不能仅凭最初发布日期声称70546当时已可得。

因此：

- 历史复现版完成了无未来观察月份的实时标准化。
- GDP release-aware 候选缺少早期初始化数据，首次有效2023-03；不满足完整2012-07历史要求，已标记不完整。
- 全因子发布日门控快照首次有效截止日2023-05-31，使用观察月份2023-04。
- 两套CSV已分开生成；严格历史vintage认证尚不能完成。这是证据缺口，不是用未来填补的理由。
