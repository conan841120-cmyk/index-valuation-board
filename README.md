## 口径变化监控（tools/watch_rule.py）

作者会改口径（2026-09-23 红利低波用市净率LF，09-27 改成股息率），所以每天自动核对一次：

1. **发现当天文章**：公众号「合集」接口（`mp/appmsgalbum`）无需登录即可列出最近文章，按标题 `【YYYY-MM-DD】…核心指数估值` 取最新一篇；
2. **下载配图**（约 21 张）后，对每张图：OCR 顶部一行拿到指数名/代码 → 匹配本项目 5 个指数；
3. **识别口径**：图里被选中的指标按钮是整块填蓝的（#4EABC4），按蓝色色块的水平位置判定是哪一个指标（不需要 OCR）；
4. **与 `compute/config.py` 比对**：不一致时——
   - 页面顶部出现红色报警条（列出「作者用 X / 本项目用 Y」）；
   - 页脚出现「口径核对：… ❌ N 处口径不一致」；
   - 工作流里该步骤返回退出码 2（`continue-on-error` 不阻塞发布，但运行结果会标红）。

本地运行：`python3 tools/watch_rule.py`（自动找最新文章）或 `--images-dir <目录>`（离线核对已有图片）。

## 看板页面

**打开方式**：云端网址直接看；或双击本地生成的 `outputs/估值看板.html`（单文件 1.5 MB，ECharts 与数据全内联，离线可用）。

版面（方向 B）：报头刊头 → 五指数索引（红线下划）→ 编辑式控件条 → 主图＋判断句＋读数表＋编者注 →
「五个指数并置」小倍数 → 页脚来源与免责。视觉 DNA：暖奶油纸底、低饱和油墨红／靛蓝／橄榄、
宋体压标题、数字等宽、细规则线（不用圆角卡片与阴影）。

页面功能：指数切换（5 个）· 时间范围（3Y/5Y/10Y/全部可用）· 指标切换（主指标 / 并排的真实 PE、PB 序列）·
视图切换（指标 / 分位点 / 标准差）· 统计与明细数据 · 移动平均线 · CSV 导出 ·
自定义分位阈值（读数表里的 ⚙）· 小倍数点选切换主图。
反向指标（股息率）自动对调方向：绿线（机会值）在上、红线（危险值）在下，区间判定同步翻转。

URL 参数（便于截图/分享特定视图）：`?index=sp500&window=5Y&view=percentile&metric=pe&tab=detail&lines=all`

## 统计口径（已反推并用两份独立数据验证）

窗口内周频序列 `x[1..n]`（默认 10 年），升序 `s[0..n-1]`，当前值 `c`：

| 字段 | 口径 |
| --- | --- |
| 当前值 | 最新一期；主股息率仅在观测日与末点同日时取蛋卷第三方锚点，否则保留模型末值，官方 dy1 另列独立 alternate，dy2 保留在数据文件 |
| 分位点 | `count(x < c) / n × 100%` |
| 中位数 | `s[⌊0.50n⌋]` |
| 危险值 | 正向指标 `s[⌊0.80n⌋]`；反向指标（股息率/风险溢价）`s[⌊0.20n⌋]` |
| 机会值 | 正向指标 `s[⌊0.20n⌋]`；反向指标 `s[⌊0.80n⌋]` |
| 最大值/平均值/最小值 | 常规统计量 |
| 标准差(+1)/(−1) | 平均值 ± 样本标准差（ddof=1） |
| z 分数 | `(c − 平均值) / 标准差` |

区间判定：正向指标 `分位点<20% 低估 / <50% 合理偏低 / <80% 合理偏高 / ≥80% 高估`；反向指标方向对调。
提示带缓冲（≥78% 提示"接近"、≥82% 才提示"进入"），避免分位点边界抖动造成单点误判。

## 已知限制

1. **股息率历史是事后估算**：主锚点仍是蛋卷第三方口径；中证官方 dy1/dy2 是不同口径；累计 CSV 的 dy1 作为独立 alternate 展示，dy2 仍保留在数据文件，不拼进主历史。
   current_anchor 使用本期锚点校准过去的分布，不能当作当时可知的择时信号。
   截图拟合容差不是历史或未来误差保证；页面红绿阴影明确命名为“阈值附近的观察缓冲区”。纳斯达克100/标普500为阈值上下各2%，两个红利指数为各5%，仅为人为设定的视觉提醒，不代表统计误差或置信区间，也不改变区间判断。
2. **数据日期分别追踪**：指标日期、价格日期和文件生成时间不是同一概念；来源更晚的价格不能冒充指标日期。
3. **中证A500 区间不足**：仅展示可获得的官方估值区间，不将点位回溯冒充早期 PE，也不保证与作者完整十年分位点一致。
4. **本期验收范围**：报告动态统计同日同口径截图的判定字段与失败数。无同期基准即写“本期未验证”；结构、公式、自洽性测试通过不等于截图数字核验通过。
5. 免费或付费数据源都需要核对口径、日期与覆盖；不能因为付费就保证与作者截图完全一致。

## 恒生指数领先指标（2026-10-02接入）

同一页面增加月度宏观指标区：双轴曲线、缺失月虚线、四项贡献、最新值、范围筛选、月度明细和CSV导出。计算口径沿用用户确认的季度末GDP映射与显式无偏加权方差；详见 [宏观模块说明](macro/hsi/README.md)。

云端同一日更工作流新增官方数据抓取及回归检查。每个来源下载或校验失败时保留有效历史，并显示抓取失败；不会把生成时间当作最新数据月份。手动更新仍使用 `gh workflow run daily.yml`，随后核对Actions结果与页面日期。

本地：`python macro/hsi/update.py` 离线计算；在 `macro/hsi` 目录运行 `python update.py --refresh` 实际抓取。`python tools/verify_local.py` 重建两个模块并检查估值与前端；宏观公式/无未来月份测试另在 `macro/hsi` 运行 `python -m pytest -q`。
