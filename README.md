## 口径变化监控（tools/watch_rule.py）

作者会改口径（2026-09-23 红利低波用市净率LF，09-27 改成股息率），所以每天自动核对一次：

1. **发现当天文章**：公众号「合集」接口（`mp/appmsgalbum`）无需登录即可列出最近文章，按标题 `【YYYY-MM-DD】…核心指数估值` 取最新一篇；
2. **下载配图**（约 21 张）后，对每张图：OCR 顶部一行拿到指数名/代码 → 匹配本项目 5 个指数；
3. **识别口径**：图里被选中的指标按钮是整块填蓝的（#4EABC4），按蓝色色块的水平位置判定是哪一个指标（不需要 OCR）；
4. **与 `compute/config.py` 比对**：不一致时——
   - 页面顶部出现红色报警条（列出「作者用 X / 本项目用 Y」）；
   - 页脚出现「口径核对：… ❌ N 处口径不一致」；
   - 工作流里该步骤返回退出码 2（`continue-on-error` 不阻塞发布，但运行结果会标红）。

本地运行：`python3 tools/watch_rule.py`（自动找最新文章）或 `--images-dir <目录>`（离线核对已有图片）。

**打开方式**：云端网址直接看；或双击本地生成的 `outputs/估值看板.html`（单文件 1.5 MB，ECharts 与数据全内联，离线可用）。

## 统计口径（已反推并用两份独立数据验证）

窗口内周频序列 `x[1..n]`（默认 10 年），升序 `s[0..n-1]`，当前值 `c`：

| 字段 | 口径 |
| --- | --- |
| 当前值 | 最新一期（股息率取官方真实值） |
| 分位点 | `count(x < c) / n × 100%` |
| 中位数 | `s[⌊0.50n⌋]` |
| 危险值 | 正向指标 `s[⌊0.80n⌋]`；反向指标（股息率/风险溢价）`s[⌊0.20n⌋]` |
| 机会值 | 正向指标 `s[⌊0.20n⌋]`；反向指标 `s[⌊0.80n⌋]` |
| 最大值/平均值/最小值 | 常规统计量 |
| 标准差(+1)/(−1) | 平均值 ± 样本标准差（ddof=1） |
| z 分数 | `(c − 平均值) / 标准差` |

区间判定：正向指标 `分位点<20% 低估 / <50% 合理偏低 / <80% 合理偏高 / ≥80% 高估`；反向指标方向对调。
提示带缓冲（≥78% 提示"接近"、≥82% 才提示"进入"），避免分位点边界抖动造成单点误判。

## 已知限制

1. **股息率历史是推导值**：红利低波/中证红利的当前股息率是官方真实值（与作者图完全一致 4.45 / 4.28），
   但 10 年历史由推导产生。实测（对照作者 2026-09-27 截图，10Y 窗口）：
   危险值 +2.4% / 中位数 +1.7% / 机会值 −3.1%，**分位点 −6.1pp**（红利低波 31.3% vs 37.4%）。
   官方真实序列自 2026-08-28 起逐日累积（每次运行落盘，真实占比随时间上升）。
2. **中证A500 真实区间只有 2 年**：中证官方估值字段自 2024-09-03 起（指数于 2024-09-23 正式发布，行情按基日回溯、**估值指标不回溯**），更早无公开真实数据，本项目不做推算。
   页面为周频（与作者图一致），故首个周点是 **2024-09-06**（2024-09-03~09-06 属同一周，取该周最后一个交易日）。
3. 若要求股息率 10 年分位点也与作者图完全一致，只能接入付费源（理杏仁开放平台），配置项已预留。

### 为什么股息率分位点仍有 6pp 偏差（根因）

以红利低波 2026-09-24 为例，同一个指数、同一天，市面上有四个不同口径的"股息率"：

| 来源 | 数值 | 说明 |
| --- | --- | --- |
| 中证官方 股息率1（总股本） | 4.27 | 官方免费接口，只有最近 ~20 个交易日 |
| 中证官方 股息率2（计算用股本） | 4.87 | 与上一行相差 **14%** |
| 蛋卷 / 理杏仁（作者截图） | 4.45 | 我们锚定的真实当前值 |
| 全收益指数法推导 | 5.29 | 高估 24%（它测的是"过去 12 个月累计分红/当前点位"，上涨行情天然偏高） |

**分位点 = 当前值在整条历史分布中的排名**，对"当前值附近的样本密度"极其敏感：在当前值附近每差 0.15，
分位点就差 5~7 个百分点（实测：4.27→29.5%、4.45→35.2%、4.60→41.5%）。
所以即使当前值 100% 正确，只要历史分布的"水平"有偏差，分位点就会漂移。

本项目用两条独立路线推导（全收益法 + PE 锚定倒数法）取几何平均，再做**近端衰减校准**：
把修正集中放在近端（避免整条序列同乘一个系数而扭曲历史分布），使分位点偏差从 −14.5pp 降到 −6.1pp，
同时把阈值类偏差控制在 3% 以内。参数 `YIELD_CALIBRATION_DAYS=1825` 是用作者截图回归选定的拟合参数。

> 影响评估：31.3% 与 37.4% 都落在 20%~50% 区间 → 判定同为「合理偏高」，结论不变。
> 只有当真值恰好落在区间边界（20%/50%/80%）附近时才可能翻转标签，因此页面对提示采用"区间 + 缓冲带"而非单点触发。
